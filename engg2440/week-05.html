Linearisation & Transfer Functions

The hinge of the course. Real models are frequently nonlinear, but almost all of classical control theory assumes linearity — so we approximate. This week linearises a state-space model about an equilibrium and then converts it to the transfer function that the control half runs on.

Why linear?

A system is linear if it obeys homogeneity and superposition, $T(a u) = aT(u)$ and $T(u_1+u_2) = T(u_1)+T(u_2)$. Products or quotients of states, and trigonometric or exponential functions of them, break this. Nonlinearity complicates simulation, and — more importantly for us — makes controller design far harder. The engineering world is consequently built on linear approximations to nonlinear reality.

Equilibrium points

Linearisation is always performed about an equilibrium: a state where, for a constant input, nothing changes.

$$f(\mathbf z^*, \mathbf u^*) = \mathbf 0$$

A pendulum has two: hanging down and balanced upright. They behave very differently — which the linearised models will reveal, and which motivates the inverted-pendulum problem the labs build toward.

The Taylor series

Linearisation is a first-order Taylor truncation. In the scalar case:

$$\tilde f(x) = f(x_0) + \frac{df(x_0)}{dx}(x - x_0)$$

The approximation is exact at $x_0$ and degrades as you move away — so a linear model is only trustworthy near the operating point it was built around. Go too far and you must re-linearise.

For a scalar function of several variables, add a gradient term per variable. For a vector-valued function, apply that to each component, which assembles into the Jacobian matrices:

$$A = \left.\frac{\partial f}{\partial \mathbf z}\right|_{*} \quad B = \left.\frac{\partial f}{\partial \mathbf u}\right|_{*} \quad C = \left.\frac{\partial g}{\partial \mathbf z}\right|_{*} \quad D = \left.\frac{\partial g}{\partial \mathbf u}\right|_{*}$$

The result is the familiar linear model $\dot{\mathbf z} = A\mathbf z + B\mathbf u$, $\mathbf y = C\mathbf z + D\mathbf u$ — but written in deviation variables, measured from the equilibrium rather than from zero. Forgetting that is a classic error.

Transfer functions

Laplace-transforming an ODE with zero initial conditions and rearranging into the ratio of output to input gives the transfer function $H(s) = Y(s)/U(s)$. Doing the same to the linear state equations lets the state vector be eliminated:

$$s\mathbf Z = A\mathbf Z + B\mathbf U \ \Rightarrow\ \mathbf Z = (sI-A)^{-1}B\,\mathbf U \ \Rightarrow\ H(s) = C(sI-A)^{-1}B + D$$

The poles of $H(s)$ are the eigenvalues of $A$ — the same dynamics seen a different way.

And back again

The reverse path is transfer function → ODE (inverse Laplace) → state-space. Note that state-space representations are not unique: going backwards you may get states that are no longer the tidy momenta and displacements you started with, because the transfer function has discarded the domain-specific structure.
