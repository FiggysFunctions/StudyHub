PID Control & the Value of Feedback

Two threads this week. First the controller structure that runs most of industry — three terms responding to the present, past and predicted future of the error. Then the systematic argument for feedback itself, comparing open and closed loop across the four properties that matter.

The three terms

$$u(t) = K_P e(t) + K_I\!\int_0^t\! e(\tau)\,d\tau + K_D\frac{de(t)}{dt} \qquad C(s) = K_P + \frac{K_I}{s} + K_D s = \frac{K_Ds^2 + K_Ps + K_I}{s}$$

As a transfer function it has one pole at the origin and two zeros. What each term does:

  • Proportional — a plain gain. Steady-state error becomes $1/(1 + G(0)K_P)$, so error only vanishes as $K_P \to \infty$ — and large $K_P$ drives the root locus toward instability. Proportional action alone always leaves an offset.
  • Integral — accumulates error, so the control action keeps growing while any error remains. It drives steady-state error to zero exactly (it raises the system type by one, per Week 9), at the cost of a slower, more oscillatory loop.
  • Derivative — responds to the rate of change of error, giving an anticipative effect. It improves stability and reduces overshoot, but amplifies measurement noise.

Practical structures

A pure derivative is improper — the numerator outranks the denominator — so it cannot be built. Real controllers add a filter pole:

$$C(s) = K_P + \frac{K_I}{s} + \frac{K_D s}{\tau_D s + 1} \qquad C(s) = K_P\!\left(1 + \frac{1}{T_i s} + \frac{T_d s}{\tau_D s + 1}\right)$$

The second (parallel form 2) parameterises the same controller by reset time $T_i$ and derivative time $T_d$, with the filter chosen in the range $T_d/10 \le \tau_D \le T_d/2$.

Tuning

Ziegler–Nichols oscillation method: set $K_I = K_D = 0$, raise $K_P$ until the closed loop oscillates steadily (marginal stability), then read the ultimate gain and oscillation period off and apply the standard table. The reaction-curve method instead fits a first-order-plus-delay model to the open-loop step response. Both are empirical starting points — useful precisely when no good model exists. With a model, pole placement (Week 9) is more systematic.

Integrator windup

A practical trap worth knowing. Every real actuator saturates. If a large error persists while the actuator is already at its limit, the integral term keeps accumulating even though the control action cannot increase. When the error finally reverses, the controller must "unwind" that accumulated integral before it responds — producing a large, late overshoot.

Anti-windup protection fixes this by stopping or back-calculating the integrator whenever the actuator is saturated.

Why feedback? Four properties

Comparing open loop ($T = GC$) with closed loop ($T = GC/(1+GC)$):

  • Stability — open loop cannot stabilise an unstable plant: cancelling a right-half-plane pole leaves the unstable mode present. Closed loop can, by shaping $AL + BP$.
  • Tracking — open loop requires $G(0)C(0) = 1$ by calibration, which drifts as the plant ages. Closed loop achieves it automatically through loop gain.
  • Disturbance rejection — open loop cannot react to a disturbance it never measures; closed loop sees the effect in the output and corrects.
  • Sensitivity — the sharpest result of all.
$$S_G^T = \frac{\partial T/T}{\partial G/G} \qquad S_{ol} = 1 \qquad S_{cl} = \frac{1}{1 + G(s)C(s)}$$

Open-loop sensitivity is exactly 1 — a 10% plant error gives a 10% output error, always. Closed loop divides that by the loop gain, so a loop gain of 100 reduces the same error roughly a hundredfold. That single line is the quantitative case for feedback control.
