Stability: Root Locus & Routh–Hurwitz

An unstable closed loop is worthless, so stability comes before every other specification. This week ties stability to pole location, gives a way to test it without solving for the poles, and shows how the poles move as a gain is turned up.

BIBO stability

A system is bounded-input bounded-output stable if every bounded input produces a bounded output:

$$|u(t)| \le K_u < \infty \quad\Longrightarrow\quad |y(t)| \le K_y < \infty$$

and this holds exactly when every pole has a strictly negative real part — all poles in the open left half-plane. Poles on the imaginary axis are marginally stable (an input at the resonant frequency produces an unbounded response), and any right-half-plane pole is unstable.

Feedback can create stability Many real systems are open-loop unstable — most modern fighter aircraft are unstable by design and simply cannot fly without active control. Feedback is what stabilises them; only then can transient performance be addressed.

The characteristic equation

For a unity-feedback loop $T(s) = C(s)G(s)/[1 + C(s)G(s)]$, so the closed-loop poles are the roots of:

$$1 + C(s)G(s) = 0 \qquad\Longleftrightarrow\qquad A(s)L(s) + B(s)P(s) = 0$$

writing the plant as $G = B/A$ and the controller as $C = P/L$. The second form shows why feedback is so powerful: the designer shapes the closed-loop polynomial through $P$ and $L$, which open-loop control cannot do.

Never cancel an unstable pole Trying to fix a right-half-plane plant pole by placing a controller zero on top of it does not work — the unstable mode is still there, and the slightest noise or disturbance makes the output grow until something saturates or breaks.

The Routh–Hurwitz criterion

We can determine how many roots lie in the right half-plane without computing them. Order the characteristic polynomial's coefficients into the Routh array:

$$a_ns^n + a_{n-1}s^{n-1} + \dots + a_1s + a_0 = 0$$

The first two rows take alternate coefficients; each subsequent row is built from determinants of the two above it. Then:

  • The system is stable if and only if every entry in the first column is positive.
  • The number of sign changes down the first column equals the number of right-half-plane roots.

Its enduring value is with symbolic coefficients: leaving a gain $K$ in the polynomial and demanding a positive first column gives the exact range of $K$ for which the loop is stable — a design result, not just an analysis one.

Root locus

The root locus plots how the closed-loop poles travel through the s-plane as a single parameter — usually the loop gain — sweeps from zero to infinity. Branches start at the open-loop poles and end at the open-loop zeros (or run off to infinity along asymptotes).

Because pole location determines stability, damping ratio and speed, one plot answers several questions at once: the gain at which branches cross into the right half-plane is the stability limit, and the gain where a branch meets a desired damping line is the design value. In practice these are generated with MATLAB (rlocus) and read for design.
